LEE BERRY CAFE — PRODUCTION STATIC WEBSITE
==========================================

CONTENTS
- index.html              Main website, SEO metadata and structured data
- styles.css              Responsive styling, transitions and 3D-inspired hero
- script.js               3D pointer parallax, mobile navigation, menu tabs/search
- assets/leeberry-logo.png  Supplied official logo
- .htaccess               Optional Apache compression, cache and security headers
- robots.txt / sitemap.xml Basic search-engine files

HOSTING / cPANEL DEPLOYMENT
1. Sign in to your hosting control panel and open File Manager.
2. Back up the current public_html folder (download it or rename/copy it).
3. Open public_html and upload the contents of this ZIP, not the ZIP's parent folder.
4. Extract the ZIP in public_html. Confirm index.html is directly inside public_html.
5. If an old index.php or index.html exists, keep the backup and make sure the new
   index.html is the active home page. Do not delete WordPress files unless you
   have decided to replace WordPress completely.
6. Visit https://www.leeberry.in in a private browser window and test desktop/mobile.
7. If your hosting uses Nginx or does not support Apache .htaccess, remove .htaccess.

MENU SOURCE
Menu names and prices are transcribed from the two-page Lee Berry Cafe menu PDF
provided in this project. Check the printed menu before launch for any later changes.
There are 48 entries across six categories.

PHOTOGRAPHY / EXTERNAL ASSETS
The food photography uses remote Unsplash image URLs and Google Fonts. An internet
connection is required to load these assets. For a fully self-hosted deployment,
replace these URLs with locally stored, licensed Lee Berry product photos.
The images are editorial food photography and are not guaranteed to depict the
exact recipe or serving sold by Lee Berry Cafe.

IMPORTANT
This is a static menu showcase only. There is no cart, payment gateway, customer
account, backend or order submission. The package does not log in to hosting or
publish changes automatically. Your hosting credentials should never be shared
in chat.
